**Computational Fluid Dynamics (CFD) Discretisation Schemes**

This code compares three different discretisation schemes that are used in Computational Fluid Dynamics: Central Difference Scheme (CDS), Upwind Difference Scheme (UDS) and Power Law Difference Sheme (PLDS). The schemes are tested for how well they model the transport property along the length of a pipe and are compared to the analytical solution. The code is designed in such a way that the velocity, U and the number of grid points, N can be adjusted to evaluate the schemes.
