1. **Power of Energy harvester:**

Case_2300 is a MATLAB file that extracts the power and efficency generated from a wind energy harvester when stimulated in a wind tunnel. The energy harvester is connected to a piezoelectric transducer that outputs a sinusoidal voltage signal onto an oscilloscope. This code calculates the power from the oscilloscope signal and the power from the wind tunnel. It then plots both over time and calculates the efficiency of the harvester.
